# BUG-006: Issues: whitespace-only and padded titles are accepted

- **Component:** Issues > Create
- **Priority:** P3
- **Found by:** exploratory session 2 (not a planted defect; found while probing input boundaries)
- **Test:** `tests/test_found_defects.py` (strict xfail)

## Summary
The title is validated with `min_length=3` but never trimmed. `"     "` (five spaces) and `"  ab  "`
(two letters with padding) both pass validation and are stored exactly as sent.

## Steps to reproduce
1. `POST /api/issues` with `{"title": "     ", "component": "Mail"}`.
2. Open the issue list.

## Expected result
HTTP 422. A title must contain at least 3 non-space characters.

## Actual result
HTTP 201. The issue is created with a blank-looking title, so it shows up in the list as an empty link
that is hard to see or click.

## Impact
Unusable list rows and noisy data. The web form is protected (it strips the title before checking the
length) but the API is not, so the two entry points disagree.

## Suggested fix
Strip the title in the schema (`str_strip_whitespace=True`) so API and web use the same rule.
